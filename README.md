# Pi Device Controller

A personal Raspberry Pi project providing a web-based control interface for a Bluetooth-connected device.

## Features
- Independent dual-motor control
- Custom vibration patterns and sequences
- Adjustable speed and intensity
- Session timers
- Battery monitoring
- Local and remote connectivity

## Development

Built using Python on a Raspberry Pi 3B+.

Currently exploring integration with the Lovense Developer API for secure remote connectivity.

**Status:** Personal, non-commercial project.
